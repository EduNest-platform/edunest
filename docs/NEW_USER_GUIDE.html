New User Quick Start Guide

📱 Step 1: Download & Install EduNest APK

📋System Requirements

  • Android Version: 6.0 (API level 23) or higher
  • Storage Space: At least 100MB free space
  • RAM: Minimum 2GB (4GB recommended)
  • Internet: Stable connection required for setup

⚙️Installation Steps

  1. Enable Unknown Sources:
    • Go to Settings → Security → Unknown Sources
    • Toggle ON "Allow installation from unknown sources"
    • For Android 8+: Settings → Apps → Special Access → Install Unknown Apps
  2. Download APK:
    • Download from the official link provided
    • Ensure download completes successfully
    • File size: Approximately 25-30MB
  3. Install Application:
    • Open Downloads folder
    • Tap on EduNest APK file
    • Follow installation prompts
    • Grant required permissions
⚠️ Important: Only download EduNest APK from official sources to ensure security and latest features.

🔐 Step 2: Create Your Account

📝Registration Process

  1. Launch EduNest:
    • Tap the EduNest icon on your home screen
    • Wait for splash screen and initial loading
    • First launch may take 10-15 seconds
  2. Choose Sign Up:
    • On welcome screen, tap "Create New Account"
    • Read and accept Terms of Service
  3. Enter Registration Details:
Required Information:
📧 Email Address: college.email@domain.com
🔑 Password: Minimum 8 characters, include numbers
👤 Full Name: Your complete legal name
📱 Phone: Mobile number (optional but recommended)
  1. Email Verification:
    • Check your email inbox (and spam folder)
    • Click verification link within 24 hours
    • Return to app and proceed with login
✅ Pro Tip: Use your college email address for better integration with institutional features and announcements.

🔧 Step 6: Troubleshooting Common Issues

🔐 Login & Account Issues

  • Forgot Password: Use reset link on login screen
  • Email Not Verified: Check spam folder
  • Account Locked: Contact support after multiple failed attempts
  • Profile Incomplete: Complete all required fields

⚡ Performance Issues

  • Slow Loading: Check internet connection stability
  • App Crashes: Restart app or reinstall if persistent
  • Storage Full: Clear app cache or free device storage
  • Battery Drain: Check background app refresh settings

🔄 Sync & Data Issues

  • Data Not Loading: Verify internet connection
  • Attendance Issues: Coordinate with professor
  • Marks Not Showing: Contact academic office
  • Files Not Downloading: Check storage permissions

📱 Device Compatibility

  • Old Android: Update to supported version
  • Low RAM: Close other apps while using EduNest
  • Storage Issues: Move other apps to SD card
  • Network Issues: Try different WiFi/mobile data
